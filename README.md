
# Go_app_for_exercise
An app created by Chatgpt for people to practice Go.
=======
# 弈境 · 围棋研习

简洁古风的围棋练习与人机对弈程序。题库界面只保留带标准变化的练习；人机部分使用本地 KataGo，不需要联网。启动时会显示约 3–4 秒的水墨手谈加载页，同时等待引擎就绪。

## 启动

1. 双击 `Go.exe`，浏览器会自动打开程序。
2. 看到“KataGo · CPU 已就绪”即可开始人机对弈。
3. 需要彻底结束后台引擎时，点击右上角“结束程序”。仅关闭浏览器页面不会破坏正在运行的一局棋。

重复双击 `Go.exe` 时，程序会检测并复用已运行的弈境服务，不会重复启动 KataGo 或抢占 8787 端口；会重新打开网页。若双击后浏览器没有自动弹出，可双击同目录的 `启动弈境.cmd`；它会等待服务就绪后再打开浏览器。启动失败时窗口会停留并显示 `Go.log`，日志也会记录 KataGo 和端口错误。

`Go.exe`、`engine`、`data` 和网页资源必须保持在同一个文件夹中。直接打开 `index.html` 可以浏览题库，但浏览器无法启动 KataGo。

## 标准答案题库

程序内置 420 道 Go Game Guru Weekly Problems，入门、进阶、挑战各 140 道。题目来自原始 SGF，答案只采用 SGF 中标注为 `Correct` 的变化路径，不由本程序编造。

题库支持入门 / 进阶 / 挑战筛选、题号搜索、自由推演、单题 SGF 下载、“演示标准答案”和本地研习进度记录。题库答案与题目来源、许可说明见 `SOURCES.md`。

## 打谱与棋谱

- “打谱”模块支持摆放黑白初始棋子、按次序落子、前后浏览、读取文件和使用 800 次 KataGo 形势判断。
- 主要支持 SGF；同时支持常见 GIB、NGF、JSON 和文本棋谱。腾讯围棋、野狐围棋导出的 SGF 可直接读取，GIB / NGF 会按其常见坐标记录转换到棋盘。
- 打谱棋谱和人机对局均可保存为 SGF 到程序目录下的 `records` 文件夹，也可以下载到其他位置。

## 人机对弈

- 支持 9 / 13 / 19 路，执黑先行，白贴 7.5 目。
- 每局开局前选择七档对弈等级，开局后锁定：新手、入门（人类10级 / 2次）、老手、业余高手、业余顶尖（人类5段 / 32次）、职业棋手（职业九段 / 64次）、AI（KataGo 一选 / 256次）。
- 人类棋力档均按对应等级的人类棋谱概率落子，逐级收窄选择分布并提高计算量；AI 档才始终选择 KataGo 一选。
- 默认投降条件为：第 150 手起，白方自身胜率低于 1% 连续 12 手后认输。
- “显示形势与推荐”按钮按需请求并显示黑白胜率、预计目差和前三候选点，再次点击即可隐藏。其搜索量可在顶部“形势深度”菜单调节，独立于对弈难度。

## 声音与界面

顶部“棋具 · 声音”菜单可选择暖竹、深木、宣纸、朱漆木纹、青石棋盘；云子、青玉、墨白、琥珀云子、青花瓷子；以及风雨声、松风、山涧流水、古琴、竹林夜雨或静默。顶部“形势深度”菜单可调节形势判断搜索量。音量滑块调节整体音量，落子、提子会播放分层木棋盘敲击音。界面使用响应式布局，1080p 和窗口化尺寸下会自动调整棋盘及侧栏。

顶部右侧按钮可以在简体中文与 English 界面之间切换，语言选择保存在本地浏览器中。

## 棋盘与规则

支持提子、自杀判定、全局同形禁止（positional superko）、停一手、悔棋、双停后的死子标记和数子结算。AI 查询失败时界面提供重试，不会偷偷换成随机引擎。

## KataGo

程序包含官方 KataGo v1.16.4 Eigen Windows x64 CPU 引擎、`kata1-b6c96-s69427456-d10051148` 网络权重和 Human SL 人类棋谱模型。服务只监听 `127.0.0.1`，通过 Analysis JSON 协议查询；详情和许可证见 `SOURCES.md` 及 `engine/LICENSE`。

## 验证

在开发目录运行 `node --test test.cjs` 可验证围棋规则、420 道标准答案路径、请求校验和数据完整性。设置 `$env:LIVE_TEST='1'` 后再运行，可额外验证真实 KataGo。
